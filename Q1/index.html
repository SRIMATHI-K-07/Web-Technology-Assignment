6. Working Principle of a Website

  1. User enters the URL in the browser.
  2. Browser contacts the DNS server.
  3. DNS finds the IP address of the server.
  4. Browser sends a request to the web server.
  5. Server processes the request.
  6. Server sends the required files to the browser.
  7. Browser interprets HTML, CSS and JavaScript.
  8. The webpage is displayed to the user.
